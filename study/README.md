# greenflame homepage design study

Public comparison at `/study/`, with variants A–E selected by `?variant=A`.
This study is separate from the production homepage. Search indexing is
discouraged with `noindex`; the page is public, not access-controlled.

The original icon and supplied screenshot are unchanged. Jost's font license
is included in `OFL-Jost.txt`. Run `node study/prototype.test.mjs` from the
repository root to check the variants, assets, and public-study controls.
